# MEwalletin

Aplikasi Dompet Digital & Manajemen Keuangan Modern (Modern Digital Wallet & Crypto Staking Web App).

## Fitur Utama
- **Multi-Currency Wallet**: Kelola saldo Rupiah (IDR) dan berbagai valuta asing (USD, EUR, JPY, SGD, dsb.).
- **Crypto Staking (Demo)**: Fitur simulasi staking koin kripto (BTC, ETH, USDT, SOL, BNB, ADA, DOT, TON).
- **Target Tabungan**: Buat dan kelola tujuan tabungan impian dengan progress bar.
- **Kirim, Minta & Top Up**: Simulasi transaksi finansial instan.
- **Kartu Virtual**: Kelola kartu debit/kredit virtual dengan fitur bekukan kartu.
- **Responsive & Dark Mode Modern**: Tampilan futuristik nan elegan dengan dukungan mobile dan desktop.

## Deploy ke Vercel
Aplikasi ini sudah dioptimalkan untuk langsung di-deploy ke Vercel tanpa konfigurasi tambahan:
1. Hubungkan repository GitHub ini di dashboard Vercel.
2. Vercel akan secara otomatis mendeteksi `index.html` dan `vercel.json`.
3. Klik **Deploy**.
